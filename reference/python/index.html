Python API¶

These are the public names of the pbzarr package. The text comes from the docstrings.

Open and write stores¶

pbzarr.open ¶

open(source: PathLike, *, tracks: str | Sequence[str] | None = None, chunks: Chunks | Literal[STORED_CHUNKS] = _STORED_CHUNKS, storage_options: Mapping[str, object] | None = None) -> xr.Dataset

Open a PBZ store as one xr.Dataset.

Every array carries the 0-d reference coordinate. tracks= limits the data variables and keeps the reference and label coordinates. By default each track is a Dask array. A track whose first dimension is genomic gets Dask chunks of about 128 MiB: whole inner chunks along positions that do not split a shard, and all columns when they fit (else whole shards of columns). Such tracks that share an inner chunk and shard grid take the smallest of their Dask chunks, so they align. Other arrays are chunked by their stored shard (or chunk) shape. chunks=None gives lazy NumPy-backed arrays, and any other value goes to xr.open_zarr. The Dataset is a snapshot: a change in memory does not reach the store. A missing local store raises FileNotFoundError, and an unknown track name raises ValueError.

pbzarr.create ¶

create(destination: PathLike, *, reference: Mapping[str, int], storage_options: Mapping[str, object] | None = None) -> xr.Dataset

Create an empty PBZ store and return it opened.

Use it to make a store for write. The import functions do not need it: they create the store from the source headers. reference is the ordered mapping of contig name to length that every track shares. The destination must be a local path that does not exist. Remote stores are not supported yet, so storage_options must be None.

pbzarr.write ¶

write(target: PathLike | Dataset, variables: Mapping[str, DataArray], *, encoding: Mapping[str, Mapping[str, Any]] | None = None, storage_options: Mapping[str, object] | None = None) -> xr.Dataset

Add new variables to a store and return the store reopened.

target is a path, a URL, or a Dataset from open (its encoding["source"] names the store). variables maps names to xr.DataArray values; an xr.Dataset is such a mapping. The checks use the store metadata of now. A genomic dimension (position or bin_N) must come first and span the reference. Shared non-genomic dimensions must match the store's labels. write never changes an existing variable, and the Dataset passed as target does not change. If the write fails, the arrays it created are removed; it is not atomic against a crash.

A new variable whose first dimension is position and that has 1 or 2 dimensions gets the import layout: inner chunks of 65,536 positions (and 1 column), shards of 1,024 inner chunks (and up to 16 columns), and Blosc zstd level 5 with shuffle. A shard is capped at the variable length rounded up to whole inner chunks, and at the variable width. When encoding= for the variable gives chunks, shards, compressors, serializer or filters, xarray chooses the layout instead. A Dask-backed value with the import layout is rechunked to whole shards, and each write task holds one shard: a shard of 16 int32 columns is 4 GiB.

Regions¶

pbzarr.region ¶

region(obj: T, query: RegionLike, *, reference: Reference | None = None) -> T

A view of one locus of a whole-genome DataArray or Dataset.

Every genomic dimension present (position and each bin_N) is sliced to the locus, and variables with no genomic dimension pass through. The view carries the 0-d coordinates region_contig, region_start and region_end. With position, it also carries a numeric pos coordinate and "contig:pos" labels as the position coordinate. Positions are 0-based and contig-local, like region_start.

pbzarr.reduce_regions ¶

reduce_regions(obj: T, intervals: Intervals, reducer: Reducer, /, *, reference: Reference | None = None, q: float | Sequence[float] | None = None, by: str | Sequence[str] | None = None, ddof: int | None = None, skipna: bool | None = None) -> T

One statistic per interval, along position.

obj is a whole-genome DataArray or Dataset. The result has the same type, with a region dimension in place of position. Row i of the result is interval i of the input, and intervals may overlap. The result carries region_contig, region_start and region_end.

reducer is one of sum, mean, min, max, count, std, var, median, quantile (needs q=) or summit (needs by=). ddof= applies to std and var. skipna= (default True) ignores NaN values.

On a Dataset, variables without a genomic dimension pass through unchanged, and variables on a bin_N dimension are left out with a warning. reference= overrides the reference coordinate, or supplies it when obj has none. The result carries the reference that was used.

pbzarr.interval_mask ¶

interval_mask(obj: DataArray | Dataset, intervals: Intervals, /, *, reference: Reference | None = None) -> xr.DataArray

A lazy bool DataArray over position: True inside any interval.

obj is a whole-genome DataArray or Dataset with a position dimension. intervals takes the forms of reduce_regions; they are 0-based and half-open, and they may overlap. The mask is a Dask array with the position chunks of obj, and it carries the reference that was used.

pbzarr.parse_region ¶

parse_region(query: str) -> RegionQuery

Parse contig, contig:start, or contig:start-end.

Coordinates are 0-based and half-open. Commas in coordinates are ignored, so chr1:1,000-2,000 is chr1:1000-2000.

pbzarr.RegionQuery dataclass ¶

pbzarr.Reference ¶

Bases: Mapping[str, int]

Ordered contig lengths; the genomic axes are their concatenation.

Coordinates are 0-based and half-open within each contig. A bin_N axis restarts at every contig, so a contig's last bin can be short.

offsets cached property ¶

offsets: ndarray

Exclusive prefix sum of lengths, one more entry than contigs.

from_xarray classmethod ¶

from_xarray(obj: DataArray | Dataset) -> Reference

The reference of a DataArray or Dataset with a reference coordinate.

size ¶

size(dim: str = 'position') -> int

Extent of a genomic dimension: position or bin_N.

resolve ¶

resolve(query: RegionLike) -> RegionQuery

One region with contig-local start and end filled in.

query takes the forms of rows. An open start is 0 and an open end is the contig end. Empty and out-of-range regions are refused.

rows ¶

rows(query: RegionLike, dim: str = 'position') -> slice

Flat rows of dim covering one region.

query is "chr1", "chr1:1000" (to the contig end), "chr1:1000-2000", a RegionQuery or a (contig, start, end) tuple. On bin_N the rows are the bins that intersect the region. Empty and out-of-range regions are refused.

interval ¶

interval(row: int, dim: str = 'position') -> RegionQuery

The contig-local interval one row of dim covers.

Import¶

pbzarr.import_d4 ¶

import_d4(destination: PathLike, track: str, sources: Source | Iterable[Source], *, dim: str | None = None, threads: int | None = None, decode_chunks: int | None = None, chunk: int | None = None, shard: int | None = None, shard_columns: int | None = None, progress: bool = False, codecs: Codecs | None = None) -> dict[str, int | float]

Import one or more D4 sources into a PBZ store.

When the destination does not exist, the import creates it from the source headers. When it exists, the import adds the track to it. A track name that the store already uses is refused. sources is a path, a (path, label) tuple, or a list of them. Give labels for all sources or for none; without labels, each column takes the file name without its format extension. A missing source file raises FileNotFoundError, and a bad argument raises ValueError. decode_chunks= sets the position chunks each reader decodes per pass (default auto). Returns the import report dict.

The layout keywords apply to each new track. chunk= is the positions per inner chunk (default 65,536). shard= is the inner chunks per shard along positions (default 1,024, so a shard holds 67,108,864 positions). shard_columns= is the columns per shard of a 2D track (default 16). The inner chunk of a 2D track is always 1 column wide. A shard is capped at the track length rounded up to whole inner chunks, and at the track width. codecs= replaces the whole chunk and shard layout, so it conflicts with the three layout keywords. Without a chunk_grid, its outer grid is 65,536 positions by up to 16 columns. A value of 0 raises ValueError.

pbzarr.import_bigwig ¶

import_bigwig(destination: PathLike, track: str, sources: Source | Iterable[Source], *, dim: str | None = None, fill: Fill | None = None, threads: int | None = None, decode_chunks: int | None = None, chunk: int | None = None, shard: int | None = None, shard_columns: int | None = None, progress: bool = False, codecs: Codecs | None = None) -> dict[str, int | float]

Import one or more bigWig sources into a PBZ store.

The track is float32. fill= is the value of bases that no bigWig interval covers: a number, or "na". None (the default) gives "na": such a base is missing and reads as NaN. Give fill=0 when the gaps mean 0. A bad fill raises ValueError.

When the destination does not exist, the import creates it from the source headers. When it exists, the import adds the track to it. A track name that the store already uses is refused. sources is a path, a (path, label) tuple, or a list of them. Give labels for all sources or for none; without labels, each column takes the file name without its format extension. A missing source file raises FileNotFoundError, and a bad argument raises ValueError. decode_chunks= sets the position chunks each reader decodes per pass (default auto). Returns the import report dict.

The layout keywords apply to each new track. chunk= is the positions per inner chunk (default 65,536). shard= is the inner chunks per shard along positions (default 1,024, so a shard holds 67,108,864 positions). shard_columns= is the columns per shard of a 2D track (default 16). The inner chunk of a 2D track is always 1 column wide. A shard is capped at the track length rounded up to whole inner chunks, and at the track width. codecs= replaces the whole chunk and shard layout, so it conflicts with the three layout keywords. Without a chunk_grid, its outer grid is 65,536 positions by up to 16 columns. A value of 0 raises ValueError.

pbzarr.import_bed ¶

import_bed(destination: PathLike, sources: Source | Iterable[Source], *, genome: PathLike | None = None, schema: Mapping[str | int, str | Mapping[str, object] | None] | None = None, track: str | None = None, column: str | int | None = None, dtype: str | None = None, fill: Fill | None = None, dim: str | None = None, chunk: int | None = None, shard: int | None = None, shard_columns: int | None = None, codecs: Codecs | None = None, threads: int | None = None, decode_chunks: int | None = None, progress: bool = False) -> dict[str, int | float]

Import tabix-indexed BED sources into a PBZ store.

The call has three forms, matching pbz import bed:

  • column= selects one BED column (a header name, or a 1-based column number of 4 or more) and imports it as one track. track= names the track; it defaults to the header name, so a numbered column needs track=. dtype= skips inference.
  • schema= maps BED columns (header names, or 1-based column numbers) to entries and imports one track per entry. An entry is a dtype string, None, or a dict with the optional keys "track", "dtype", and "fill". The track takes the header name when the entry gives none, so a numbered column needs "track". A missing dtype is inferred across every source, and a missing fill takes fill=. schema= conflicts with track=, column=, and dtype=.
  • With none of those, BED3 input imports a bool presence track and headerless BED4 one value track (both need track=). Headered input imports every value column: one wide track when a single source has track= set, else one track per column.

Output is 2D when there are several sources, or when one track holds several BED columns. Every 2D output requires dim=.

fill= is the value of bases that no interval covers in a value column: a number, True or False for a bool column, or "na". "na" is the null of the dtype: NaN for a float, the type maximum for an integer. None (the default) gives "na", and False for a bool column. With "na", dtype inference keeps the type maximum free. Give fill=0 when the gaps mean 0. A BED3 mask always holds False and refuses fill=. A bad fill raises ValueError.

xarray decodes an integer track with the null to a float dtype, with NaN at the nulls: float32 for 8- and 16-bit integers, float64 for 32- and 64-bit integers.

BED files have no contig lengths. When the destination does not exist, the import creates it with the lengths in genome=, a .fai or chrom.sizes file. When it exists, the store gives the lengths, and genome= is optional; if given, it must match the store. A track name that the store already uses is refused. sources is a path, a (path, label) tuple, or a list of them. Give labels for all sources or for none; without labels, each column takes the file name without its format extension. A missing source file raises FileNotFoundError, and a bad argument raises ValueError. decode_chunks= sets the position chunks each reader decodes per pass (default auto). Returns the import report dict.

The layout keywords apply to each new track. chunk= is the positions per inner chunk (default 65,536). shard= is the inner chunks per shard along positions (default 1,024, so a shard holds 67,108,864 positions). shard_columns= is the columns per shard of a 2D track (default 16). The inner chunk of a 2D track is always 1 column wide. A shard is capped at the track length rounded up to whole inner chunks, and at the track width. codecs= replaces the whole chunk and shard layout, so it conflicts with the three layout keywords. Without a chunk_grid, its outer grid is 65,536 positions by up to 16 columns. A value of 0 raises ValueError.

pbzarr.import_bam ¶

import_bam(destination: PathLike, track: str, sources: Source | Iterable[Source], *, mode: Literal['depth', 'composition'] = 'depth', fasta: PathLike | None = None, min_mapq: int = 0, exclude_flags: int = 1796, min_bq: int = 0, overlap: Literal['proper', 'all', 'none'] = 'proper', count_deletions: bool = False, dim: str | None = None, chunk: int | None = None, shard: int | None = None, shard_columns: int | None = None, threads: int | None = None, decode_chunks: int | None = None, progress: bool = False, codecs: Codecs | None = None) -> dict[str, int | float]

Import per-base depth or composition counts from BAM/CRAM sources.

mode is "depth" (writes track) or "composition" (writes track plus one track_{field} per composition field). CRAM sources need fasta; BAM sources ignore it. count_deletions defaults to False, matching the samtools/mosdepth/Picard/riker convention that CIGAR D positions do not count toward depth; set True to count deletion spans toward depth (useful for callability masks). overlap controls mate-overlap dedup: "proper" (default) matches mosdepth, collapsing only PROPER_PAIR-flagged overlapping mates to one count; "all" matches riker/samtools-mpileup-style unconditional dedup of any overlapping mate pair; "none" disables dedup, double-counting every overlapping pair's shared span. When the destination does not exist, the import creates it from the source headers. When it exists, the import adds the track(s) to it. A track name that the store already uses is refused. decode_chunks= sets the position chunks each reader decodes per pass (default auto). Returns the import report dict.

sources is a path, a (path, label) tuple, or a list of them. Give labels for all sources or for none; without labels, each column takes the file name without its format extension. A missing source file raises FileNotFoundError, and a bad argument raises ValueError.

The layout keywords apply to each new track. chunk= is the positions per inner chunk (default 65,536). shard= is the inner chunks per shard along positions (default 1,024, so a shard holds 67,108,864 positions). shard_columns= is the columns per shard of a 2D track (default 16). The inner chunk of a 2D track is always 1 column wide. A shard is capped at the track length rounded up to whole inner chunks, and at the track width. codecs= replaces the whole chunk and shard layout, so it conflicts with the three layout keywords. Without a chunk_grid, its outer grid is 65,536 positions by up to 16 columns. A value of 0 raises ValueError.
